# Shifter Portfolio

Interactive floating-room portfolio for Pavel / Shifter.

## Stack

- Next.js App Router
- TypeScript
- Tailwind CSS v4
- Framer Motion
- Lucide React

## Local development

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Quality checks

```bash
npm run lint
npm run build
```

## Concept

The site is a cozy floating room above the clouds. Every object reveals part of Pavel's identity: projects, skills, languages, certificates, basketball, games, goals, and Agent Capicode.
